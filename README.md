# AutoDNS Windows

Утилита для Windows 11, которая сравнивает Comss и GeoHide EU, применяет выбранный DNS и сохраняет исходную конфигурацию для отката.

## Запуск

На GitHub нажмите **Code → Download ZIP**, распакуйте архив и откройте **`AutoDNS.cmd`**. Все действия доступны в одном меню. Для изменения DNS и управления заданием Windows запросит права администратора.

| Пункт | Действие |
| --- | --- |
| **1** | Открыть HTML-отчёт о DNS адаптера, адресах Comss и ответах DoH. |
| **2** | Сравнить Comss и GeoHide EU без изменения настроек. |
| **3** | Сравнить провайдеров и применить лучший результат. |
| **4** | Обновить адреса Comss вручную. |
| **5** | Переключиться на GeoHide EU вручную. |
| **6** | Восстановить DNS, которые были до переключения. |
| **7** | Включить автообновление Comss раз в два часа. |
| **8** | Удалить задание автообновления. |
| **9** | Открыть отчёт со статусом задания Comss и его журналом. |

По умолчанию меню работает с адаптером `Ethernet`. Для другого адаптера выполните `Get-NetAdapter` в PowerShell и передайте его имя при запуске:

```powershell
.\AutoDNS.cmd -InterfaceAlias 'Wi-Fi'
```

## Как выбирается DNS

Чтобы проверить прямое подключение, отключите VPN и выберите **2** или **3**. Для каждого провайдера оба адреса должны открыть контрольный сайт через DoH. Побеждает провайдер, у которого больше успешных HTTPS-запросов к Steam и ChatGPT. При равном результате сравнивается среднее время успешных запросов. Если оба провайдера не прошли условия, настройки сохраняются.

Проверки показывают доступность главных страниц без входа в аккаунт. Работу магазина в клиенте Steam и отправку сообщений в Codex проверяйте отдельно.

## Откат и автообновление

Пункты **3** и **5** сохраняют исходные статические IPv4 DNS или режим автоматического получения DNS и приостанавливают задание Comss. Пункт **6** восстанавливает сохранённую конфигурацию и прежнее состояние задания. Держите резервную копию в распакованной папке до завершения отката.

Пункт **7** устанавливает задание `Comss DNS - every 2 hours`. Первая проверка выполняется через минуту. Не включайте это задание и не запускайте ручное обновление Comss во время проверки другого провайдера: они могут заменить выбранные DNS. Удаление задания оставляет последние применённые адреса в Windows.

Утилита меняет только IPv4 DNS выбранного адаптера. Для Comss и GeoHide используется DoH без автоматического перехода на незашифрованный DNS.

## Локальные файлы

- `comss-dns.log` — журнал ручного обновления.
- `comss-dns-report.html` — последний отчёт диагностики.
- `geohide-dns-backup.json` — резервная копия для отката.
- `%ProgramFiles%\ComssDnsUpdater\comss-dns.log` — журнал задания Windows.

Локальные журналы, отчёт и резервная копия исключены из Git.
