# AutoDNS Windows

Утилита для Windows 11, которая сравнивает Comss, GeoHide EU и Перевал, применяет выбранный DNS и сохраняет исходную конфигурацию для отката.

## Запуск

На GitHub нажмите **Code → Download ZIP**, распакуйте архив и откройте **`AutoDNS.cmd`**. Все действия доступны в одном меню. Для изменения DNS и управления заданием Windows запросит права администратора.

| Пункт | Действие |
| --- | --- |
| **1** | Открыть HTML-отчёт о DNS адаптера, адресах Comss и ответах DoH. |
| **2** | Сравнить Comss, GeoHide EU и Перевал без изменения настроек. |
| **3** | Сравнить провайдеров и применить лучший результат. |
| **4** | Подключить Comss. |
| **5** | Подключить GeoHide. |
| **6** | Восстановить DNS, которые были до переключения. |
| **7** | Включить автообновление Comss или GeoHide раз в два часа. |
| **8** | Отключить автообновление. |

В пункте **1** отчёт также показывает IPv4, которые Windows вернула для Steam и ChatGPT. Для каждого адреса с маршрутом через выбранный адаптер выполняются две попытки открыть страницу по HTTPS с тайм-аутом 10 секунд. Один успешный запрос из двух отмечается предупреждением, два сбоя — ошибкой. Код curl 28 означает тайм-аут даже при полученных заголовках HTTP 200.

Чтобы добавить к отчёту статус задания и его журнал, откройте `AutoDNS.cmd` от имени администратора и выберите **1**.

По умолчанию меню работает с адаптером `Ethernet`. Для другого адаптера выполните `Get-NetAdapter` в PowerShell и передайте его имя при запуске:

```powershell
.\AutoDNS.cmd -InterfaceAlias 'Wi-Fi'
```

## Как выбирается DNS

Чтобы проверить прямое подключение, отключите VPN и выберите **2** или **3**. Через каждый DNS-адрес программа проверяет контрольный сайт `ya.ru` и делает по два HTTPS-запроса к Steam и ChatGPT. Адрес должен открыть контрольный сайт и хотя бы по разу открыть Steam и ChatGPT. Провайдер проходит проверку, если прошли все его адреса. Побеждает провайдер с наибольшей долей успешных запросов к Steam и ChatGPT. При равной доле сравнивается среднее время успешных запросов. Если ни один провайдер не прошёл проверку, настройки сохраняются.

Проверки показывают доступность главных страниц без входа в аккаунт. Работу магазина в клиенте Steam и отправку сообщений в Codex проверяйте отдельно.

## Откат и автообновление

Пункты **3**, **4** и **5** сохраняют исходные статические IPv4 DNS или режим автоматического получения DNS и приостанавливают автообновление. Можно менять провайдера без промежуточного отката. Пункт **6** восстанавливает конфигурацию, сохранённую до первого переключения, и прежнее состояние заданий. Держите резервную копию в распакованной папке до завершения отката.

В пункте **7** выберите провайдера. Первая проверка выполняется через минуту, следующие — каждые два часа. Включение расписания для одного провайдера отключает расписание другого. Пункт **8** отключает оба расписания и сохраняет установленные DNS.

Если Comss публикует только адрес DoH, утилита получает IPv4 для этого имени и проверяет два сервера запросами DoH. При наличии списка стандартных серверов Comss берёт адреса с сайта, а GeoHide — из IPv4-записей `eu.geohide.ru`. Перед применением GeoHide проверяет ответы по DoH и сохраняет порядок текущих адресов, если оба продолжают работать. Если не удаётся подобрать два адреса, настройки остаются прежними.

Перевал публикует один IPv4-адрес (`153.80.200.170`). Если автоподбор выбирает его, Windows получает этот адрес с шаблоном `https://free.pereval.top/dns-query`.

Утилита меняет только IPv4 DNS выбранного адаптера. Для всех трёх провайдеров используется DoH без автоматического перехода на незашифрованный DNS.

## Локальные файлы

- `comss-dns.log` — журнал ручного обновления.
- `comss-dns-report.html` — последний отчёт диагностики.
- `geohide-dns-backup.json` — резервная копия для отката.
- `%ProgramFiles%\ComssDnsUpdater\comss-dns.log` и `%ProgramFiles%\GeoHideDnsUpdater\comss-dns.log` — журналы заданий Windows.

Локальные журналы, отчёт и резервная копия исключены из Git.
