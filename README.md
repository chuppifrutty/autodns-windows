# AutoDNS Windows

Набор скриптов для Windows 11. Сравнивает Comss и GeoHide EU на вашем подключении, применяет выбранный DNS и сохраняет исходную конфигурацию для отката. Для работы нужен Windows PowerShell 5.1. По умолчанию используется адаптер `Ethernet`.

## Быстрый запуск

Скачайте архив через **Code → Download ZIP** на GitHub и распакуйте его. Запускайте CMD-файлы из распакованной папки вместе с соседними PS1-файлами.

| Файл | Что делает |
| --- | --- |
| `Check-ComssDns.cmd` | Создаёт и открывает HTML-отчёт. Показывает IPv4 DNS адаптера, адреса на сайте Comss, ответы DoH и сетевой интерфейс, через который прошла проверка. Настройки сети не меняет. |
| `Update-ComssDns.cmd` | Загружает текущую пару IPv4-адресов с сайта Comss, регистрирует DoH и при необходимости обновляет DNS на Ethernet. Запрашивает права администратора. |
| `Switch-GeoHideDns.cmd` | Сравнивает Comss и GeoHide EU и применяет победителя. Также позволяет выбрать GeoHide вручную или восстановить сохранённую конфигурацию. Запрашивает права администратора. |

Чтобы посмотреть статус защищённого задания Comss и его журнал в отчёте, запустите `Check-ComssDns.cmd` от имени администратора.

## Автоматическое обновление Comss

Откройте PowerShell от имени администратора в распакованной папке и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-ComssDnsTask.ps1
```

Задание `Comss DNS - every 2 hours` запускает первую проверку через минуту, затем каждые два часа. Скрипты для задания и его журнал находятся в `%ProgramFiles%\ComssDnsUpdater`. Если страница Comss недоступна или на ней не удаётся найти пару ожидаемых адресов, обновление прерывается.

Для другого сетевого адаптера уточните его имя через `Get-NetAdapter` и передайте `-InterfaceAlias`. Например:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-ComssDnsTask.ps1 -InterfaceAlias 'Wi-Fi'
.\Check-ComssDns.cmd -InterfaceAlias 'Wi-Fi'
```

Чтобы удалить задание, выполните в PowerShell от имени администратора:

```powershell
Unregister-ScheduledTask -TaskName 'Comss DNS - every 2 hours' -Confirm:$false
```

После удаления задания последние установленные DNS сохраняются в Windows.

## Автоматический выбор DNS и откат

1. Для проверки прямого подключения отключите VPN.
2. Запустите `Switch-GeoHideDns.cmd` и выберите **3**. Скрипт проверит оба DNS-адреса каждого провайдера через DoH. Каждый адрес должен открыть контрольный сайт, а провайдер должен пройти хотя бы одну проверку Steam или ChatGPT. При равном числе успешных проверок побеждает провайдер с меньшим средним временем ответа успешных запросов к Steam и ChatGPT. Если подходящего провайдера нет, IPv4 DNS остаётся прежним.
3. Для отката выберите **2** в том же меню. Восстанавливаются исходные статические IPv4 DNS или автоматическое получение DNS, а также состояние задания Comss. Не удаляйте локальную резервную копию до отката.

Пункт **1** применяет GeoHide EU вручную. При применении скрипт приостанавливает включённое задание Comss, чтобы оно не перезаписало выбранный профиль. Ручной запуск обновления Comss всё ещё может заменить DNS.

Для сравнения без изменения настроек или без прав администратора:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Switch-GeoHideDns.ps1 -CheckOnly
```

Переключатель работает с IPv4. Для Comss и GeoHide используется DoH без автоматического перехода на незашифрованный DNS. Проверки Steam и ChatGPT измеряют открытие главных страниц без входа в аккаунт. Работу магазина в клиенте Steam и отправку сообщений в Codex проверяйте отдельно.

## Локальные файлы

- `comss-dns.log` — журнал ручных проверок и обновлений.
- `comss-dns-report.html` — последний отчёт диагностики.
- `geohide-dns-backup.json` — резервная копия DNS и состояния задания для отката.

Эти файлы создаются на компьютере при использовании и исключены из Git.
